# Virtual Fly Snake

A small, reproducible experiment that uses a **VFB-derived connectivity graph** as the fixed wiring of a Snake controller. The controller learns its connection strengths with tabular reinforcement learning.

> Important: Virtual Fly Brain is an atlas and data service, not a complete executable fly-brain simulator. This project therefore uses a reduced graph exported from VFB. The bundled `data/example_vfb_graph.json` is only a schema-valid demo graph; replace it with real VFB-derived edges before making biological claims.

## Quick start

This baseline uses only the Python standard library for training:

```powershell
cd D:\virtual-fly-snake
python -m vfsnake.train --episodes 5000 --graph data\example_vfb_graph.json
```

To watch a trained policy, install the optional renderer:

```powershell
python -m pip install -r requirements.txt
python -m vfsnake.play --qtable artifacts\qtable.json --graph data\example_vfb_graph.json
```

### Cách trình diễn

1. Bấm **Bắt đầu mô phỏng**.
2. Dùng **1×** để cho thấy agent thử-sai chậm và dễ giải thích; dùng **20×** để tích lũy nhiều episode.
3. Chỉ vào khu vực **Dòng lệnh não ruồi đang thực thi** để giải thích chuỗi `observation → VFB activation → action → reward → Q-learning`.
4. Khi có `+10`, đó là lúc ăn quả; khi có `-10`, đó là va chạm; `-0.05` là chi phí mỗi bước.
5. Bấm **Tạm dừng** trước khi thuyết trình từng con số. Bấm **Chơi lại** để bắt đầu một lượt học mới.

Để dừng server, quay lại cửa sổ PowerShell và nhấn `Ctrl+C`. Nếu cổng `8765` đang được dùng, đóng server cũ hoặc chạy với cổng khác rồi mở đúng URL mới.

The observation is local and intentionally compact: danger straight/left/right, fruit straight/left/right, and current heading. Actions are relative turns: left, straight, right. A reward is given for eating fruit, with penalties for collisions and a small step cost to encourage efficient paths.

## Replacing the demo graph with VFB data

The default graph is now `data/vfb_real_subgraph.json`, a dated snapshot of 12 real `synapsed_to` edges queried from the public VFB Neo4j database. It also contains explicitly marked `interface_edges`: these are the experiment's mapping between Snake signals and VFB neuron IDs, not biological synapses. The website reports the counts separately.

The browser dashboard also includes a live execution trace. Each simulation tick displays the current observation, activated VFB nodes, epsilon-greedy action, reward, and Q-learning update generated by the running loop.

Create an edge-list JSON with this shape:

```json
{
  "source": "VFB neuron or region identifier",
  "edges": [
    {"source": "visual_input", "target": "navigation", "weight": 1.0}
  ]
}
```

The loader accepts either a top-level `edges` array or an object containing `edges`. Node names are labels from the VFB export; they are not silently invented or mapped to biological functions. Use `vfsnake.vfb_graph.VFBGraph.from_edge_list` to validate and load the graph.

For a real dataset, document the VFB query/export URL, release/date, identifiers, and any filtering or aggregation in `data/README.md`. The controller maps game features to graph input nodes and three graph outputs to actions; those mappings must be stated explicitly for reproducibility.

## Project layout

- `vfsnake/game.py` - deterministic Snake environment
- `vfsnake/vfb_graph.py` - validated VFB edge-list adapter
- `vfsnake/controller.py` - graph controller and feature mapping
- `vfsnake/train.py` - tabular Q-learning CLI
- `vfsnake/play.py` - optional pygame viewer
- `tests/` - fast unit tests

## Caveat

This is a computational experiment inspired by VFB connectivity, not a claim that the reduced graph is a biologically faithful fly nervous system. Compare it with non-VFB baselines and report the graph provenance.
